# Serwery Node.js
Repozytorium zawiera dwa serwery: HTTP oraz REST zaimplementowane w Node.js z Express.js oraz Sequelize z sqlite3.

## Serwer HTTP
Strona HTML do rezerwacji sprzętu sportowego z minimalnym frontendem wykorzystującym EJS.

## Serwer REST
Serwis REST api do rezerwacji sprzętu sportowego.
